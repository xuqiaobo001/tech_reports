# 华为云按需计费机制分析报告

> 分析日期：2026-04-21

## 一、核心概念

按需计费（Pay-per-Use）是华为云的一种**先使用后付费**计费模式，用户无需任何预付款或长期承诺，按实际使用量进行计费。适用于短期、突增或不可预测的业务场景，例如电商抢购、临时测试、科学计算等。

---

## 二、计费粒度与结算周期

华为云按需产品根据使用量类型的不同，分为**三种结算周期**：

| 结算周期 | 适用场景 | 扣费时间点 | 示例 |
|---------|---------|-----------|------|
| **按小时** | 云服务器 ECS、云硬盘等按时长计费的服务 | 使用后 **1 小时内** 扣费 | 8:00~9:00 的费用，10:00 前完成扣费 |
| **按天** | 部分按天计量的服务（如日峰值带宽） | 次日 **03:00** 后扣费；日峰值计费产品约次日 **16:00** 扣费 | 5月11日的费用，5月12日 03:00 左右扣费 |
| **按月** | 部分按月计量的服务（如 95 计费带宽） | 次月 1 号 **01:00** 左右扣费；95 计费产品约次月 1 号 **20:00** 扣费 | 4月费用，5月1日 01:00 左右扣费 |

### 计费最小粒度

- 以 ECS 为例，计费粒度为**按秒计费**
- 计费公式：`资源单价 / 3600 × 使用秒数`

---

## 三、计费时间点详解（以 ECS 为例）

### 时间线示例

```
假设：2023/04/18 9:59:30 创建 ECS → 10:45:46 删除 ECS

┌──────────────────────────────────────────────────────────┐
│ 计费周期 1: 9:00:00 ~ 10:00:00                           │
│   实际使用: 9:59:30 ~ 10:00:00                           │
│   计费时长: 30 秒                                        │
├──────────────────────────────────────────────────────────┤
│ 计费周期 2: 10:00:00 ~ 11:00:00                           │
│   实际使用: 10:00:00 ~ 10:45:46                           │
│   计费时长: 2746 秒                                       │
└──────────────────────────────────────────────────────────┘
```

### 关键规则

| 规则 | 说明 |
|------|------|
| **计费起点** | 实例**创建成功**的时间点（控制台显示的"启动时间"），非发起创建的时间 |
| **计费终点** | 实例**删除/释放**时间点 |
| **结算时间** | 每个小时整点结算（UTC+8） |
| **结算完毕** | 进入新的计费周期 |

---

## 四、各计费项独立计费

一台 ECS 实例涉及多个计费项，**各自独立计费**：

| 资源类型 | 计费公式 | 说明 |
|---------|---------|------|
| 云服务器（vCPU + 内存） | 实例规格单价 × 计费时长 | 按秒计费 |
| 镜像 | 镜像单价 × 计费时长 | 公共镜像大多免费，市场镜像按供应商定价 |
| 云硬盘（系统盘 + 数据盘） | 云硬盘单价 × 计费时长 | 不受关机影响，关机仍计费 |
| 带宽（按带宽计费） | 阶梯计费：0~5Mbit/s 统一单价，>5Mbit/s 按 Mbit/s 计费 | 关机仍计费 |
| 弹性公网 IP 流量 | 按实际使用流量计费 | 仅按流量计费模式下 |

---

## 五、变更配置时的计费

一个小时内变更配置，会产生**多条计费记录**：

```
示例：9:00:00 购买 s7.medium.2 → 9:30:00 升配为 s7.medium.4

┌──────────────────────────────────────────────────────────┐
│ 9:00:00 ~ 9:30:00  →  按 s7.medium.2 单价计费            │
├──────────────────────────────────────────────────────────┤
│ 9:30:00 ~ 10:00:00 →  按 s7.medium.4 单价计费            │
└──────────────────────────────────────────────────────────┘

在 9:00:00 ~ 10:00:00 计费周期内产生两条计费信息
```

## 六、关机计费策略

关机后不同资源的计费策略取决于**实例类型**：

### 普通实例（非裸金属、无本地盘、无 FPGA）

| 资源 | 关机是否计费 | 说明 |
|------|------------|------|
| vCPU / 内存 | **不计费** | 公共资源池：基础资源释放；专属资源/边缘可用区：资源保留 |
| 镜像 | **不计费** | 资源保留，不收费 |
| GPU | **不计费** | GPU 资源不再保留 |
| 云硬盘 | **计费** | 正常计费 |
| 带宽 | **计费** | 正常计费 |

### 特殊实例（裸金属 / 本地盘 / FPGA）

| 资源 | 关机是否计费 | 说明 |
|------|------------|------|
| vCPU / 内存 | **计费** | 不受关机影响，如需停止计费须删除实例 |
| 镜像 | **计费** | — |
| GPU | **计费** | — |
| 云硬盘 | **计费** | — |
| 带宽 | **计费** | — |

## 七、费用精度

实际扣费精确到**分（0.01 元）**，分以后的金额为抹零金额，直接抹去。

> **示例**：消费 512.12456789 元 → 实际扣费 **512.12 元**，0.00456789 元抹去。

---

## 八、欠费处理流程

```
正常使用 ──→ 欠费（账户余额为负）──→ 宽限期（资源仍可用）──→ 保留期（资源冻结）──→ 资源释放（不可恢复）
```

### 关键要点

- 某个按需业务欠费**不会**影响其他按需业务（其他业务到自己的结算周期才会判断）
- 欠费通知：邮件、短信、站内信通知华为云账号创建者
- 宽限期和保留期时长根据**客户等级**不同而不同
- 保留期到期后，云服务器、云硬盘和弹性公网 IP 都将被释放，**数据无法恢复**

---

## 九、按需计费 vs 包年/包月对比

| 维度 | 按需计费 | 包年/包月 |
|------|---------|----------|
| 付费方式 | 后付费（先使用后付费） | 预付费（先付费再使用） |
| 计费粒度 | 秒级 | 月/年 |
| 结算周期 | 按小时/按天/按月（视服务而定） | 按订单购买周期 |
| 适用场景 | 短期、弹性、突发业务 | 长期稳定业务 |
| 折扣 | 无 | 购买周期越长折扣越大 |
| 灵活性 | 高（随时创建/释放） | 低（需提前购买） |

---

## 十、总结

华为云按需计费的核心机制可以概括为：

1. **先使用后付费** — 无需预付，按实际用量计费
2. **秒级精度** — 最小计费粒度为秒（如 ECS）
3. **三种结算周期** — 按小时/按天/按月，因服务而异
4. **延迟出账** — 通常在使用后 1 个结算周期内完成扣费
5. **精确到分** — 费用精确到 0.01 元，超出部分抹零
6. **各计费项独立** — 同一实例的不同资源独立计费
7. **关机不一定免费** — 仅普通实例的 vCPU/内存不计费，其余资源仍计费
