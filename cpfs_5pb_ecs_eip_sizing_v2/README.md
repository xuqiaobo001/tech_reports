> 设计日期：2026-05-08

## 一、关键发现：阿里云 EIP 带宽上限

### 1.1 EIP 带宽硬限制

| 计费模式 | 单 EIP 最大带宽 | 实际有效吞吐 | 日传输量 |
|---------|---------------|-------------|---------|
| **按流量计费** | **200 Mbit/s** | ~25 MB/s | **~2.16 TB/天** |
| **按带宽计费** | **500 Mbit/s** | ~62.5 MB/s | **~5.4 TB/天** |

```
这意味着:
  5PB 全量迁移，使用单台 ECS + 单 EIP:
  - 按流量计费: 5,120 TB ÷ 2.16 TB/天 ≈ 2,370 天 ≈ 6.5 年 ❌
  - 按带宽计费: 5,120 TB ÷ 5.4 TB/天 ≈ 948 天 ≈ 2.6 年 ❌

结论: 单 EIP 方案完全不可行，必须使用带宽聚合或专线
```

### 1.2 ECS 内网带宽 vs EIP 带宽

```
实际公网吞吐 = MIN(EIP 配置带宽, ECS 内网带宽)

                    ┌──────────────┐
                    │   ECS 内网    │  ← 内网带宽很高 (12-100 Gbps)
                    │  带宽上限     │     但对公网出口无用
                    └──────┬───────┘
                           │
                    ┌──────▼───────┐
                    │   EIP 带宽   │  ← 真正的公网出口瓶颈
                    │  上限 200/   │     单 EIP 最大 200-500 Mbit/s
                    │  500 Mbit/s  │
                    └──────────────┘

ECS 内网读写阿里云 OSS: 不受限，可达 10+ Gbps ← 免费
ECS 经 EIP 写华为云 OBS: 受限于 EIP 上限 ← 收费
```

### 4.2 Internet 共享带宽说明

```
阿里云 Internet 共享带宽 (Internet Shared Bandwidth):
  - 提供Region级别的公网出口带宽池
  - 可绑定多个 EIP，共享带宽配额
  - 支持按带宽计费或按增强型95计费
  - 单个共享带宽实例: 最高可达数 Gbps（需申请提高配额）

优势:
  - 多个 ECS 的 EIP 汇聚到一个大带宽池
  - 避免单个 EIP 的 200/500 Mbit/s 限制
  - 按带宽计费模式下，流量不额外收费
```

### 4.3 方案 A 配置

```
目标吞吐: 5 PB / 14 天 ≈ 43 Gbps 等效带宽
考虑 70% 效率: 需要 ~62 Gbps 配置

但 Internet 共享带宽单 Region 实际上限有限（通常 1-10 Gbps）
实际可行配置:

  共享带宽实例: 10 Gbps (需联系阿里云申请配额)
  传输 ECS: 4 台 ecs.g8i.2xlarge (8C/32G)
  每台 ECS 绑定 1 个 EIP (500 Mbit/s 按带宽)
  4 个 EIP 加入共享带宽池

  预期出口吞吐: ~8 Gbps 实际（10 Gbps × 80%）

  迁移时间:
    5,242,880 GB ÷ (8 Gbps ÷ 8 × 86400 × 0.8)
    = 5,242,880 GB ÷ (1 GB/s × 69120)
    ≈ 76 天

  仍然太慢！10 Gbps 共享带宽不够
```

**结论：方案 A 在 14 天内完成 5PB 不可行，除非共享带宽配额提升到 40+ Gbps。**

### 4.4 方案 A 调整：延长周期至 60 天

```
  共享带宽: 10 Gbps
  实际出口: ~8 Gbps ≈ 1 GB/s
  迁移时间: 5,242,880 GB ÷ (1 × 86400 × 0.8) ≈ 76 天

  费用:
    共享带宽 10Gbps × 60天: ~¥60 万 (按 ¥10万/月/Gbps 估算)
    ECS 4 台 × 60 天: ~¥17 万
    流量费: ¥0（按带宽计费模式下不收流量费）
    OSS 存储: ¥67 万（2个月）
    合计: ~¥144 万
```

## 六、方案 C：华为云 OMS 托管迁移（强烈推荐）

### 6.1 架构

```
┌──────── 阿里云 ────────────────────────────────┐
│                                                 │
│  CPFS ──(Data Flow 内置)──→ 阿里云 OSS           │
│                              │                  │
│  仅需 1 台管控 ECS（盘点/调度/挂载 CPFS）         │
│                              │                  │
└──────────────────────────────┼──────────────────┘
                               │
                    华为云 OMS 托管服务
                    （华为云基础设施传输）
                    费率: ¥0.01/GB
                               │
┌──────────────────────────────┼──────────────────┐
│                              ▼                  │
│  华为云 OBS ←── OBS ←── SFS Turbo              │
│                                                 │
│  1 台同步 ECS (obsutil sync, OBS→SFS Turbo)      │
│                                                 │
└─────────────────────────────────────────────────┘
```

### 6.2 OMS 方案优势

```
1. 零 ECS 传输集群: 华为云 OMS 使用自己的基础设施拉取数据
   不需要在阿里云部署传输 ECS 集群
   不需要 EIP / 共享带宽

2. 费率极低:
   OMS: ¥0.01/GB × 5,242,880 GB = ¥52,429 ≈ ¥5.2 万
   vs EIP 按流量: ¥0.50/GB × 5,242,880 GB = ¥262 万
   节省 98%！

3. 阿里云侧仅需:
   1 台 ECS: 管控用途（挂 CPFS、盘点、触发 Data Flow）
   无需 EIP 高带宽（仅管理用 5 Mbps）

4. 迁移速度:
   OMS 使用华为云全球传输基础设施
   可创建多个迁移任务组并行
   预计 7-21 天完成 5PB
```

### 6.3 OMS 操作步骤

```
阿里云侧准备:
1. CPFS Data Flow 全量导出到 OSS (同区域, ~2-5 天)
2. 确认 OSS 桶可公网访问（OMS 需要能读到 OSS）
3. 创建阿里云 RAM 只读 AK/SK 给 OMS 使用

华为云侧操作:
1. 创建目标 OBS 桶
2. OMS 控制台 → 创建迁移任务组:
   - 源端类型: 阿里云 OSS
   - 源端区域: oss-cn-hangzhou
   - 源端 AK/SK: 阿里云只读 AK
   - 目标桶: ai-datasets-5pb
   - 迁移范围: 全桶
3. 启动迁移 → 监控进度

增量同步（OMS 不擅长增量，需配合 rclone）:
4. 部署 1 台华为云 ECS 运行 rclone
   rclone copy aliyun-oss:migration-bucket huawei-obs:ai-datasets-5pb \
     --update --use-server-modtime --fast-list
```

### 混合方案（最优实践）

```
Phase 1: 存量全量（OMS 托管）
  CPFS → Data Flow → 阿里云 OSS → 华为云 OMS → 华为云 OBS
  阿里云侧: 1 台管控 ECS, 无传输集群

Phase 2: 增量收敛（rclone 补充）
  阿里云 OSS → rclone (华为云 ECS) → 华为云 OBS
  阿里云侧: 0 台新增 ECS
  华为云侧: 1 台 ECS 运行 rclone（通过公网读阿里云 OSS）

Phase 3: OBS → SFS Turbo
  华为云侧 1 台 ECS 运行 obsutil sync
```
