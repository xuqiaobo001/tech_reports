# 华为云IAM服务 SAML 单点登录(SSO)对接测试用例

> **测试对象**: 华为云IAM身份提供商 — 基于SAML 2.0协议的联邦身份认证（单点登录）
> **测试范围**: 虚拟用户SSO 和 IAM用户SSO 两种模式的全流程测试
> **参考文档**: https://support.huaweicloud.com/iam/index.html

---

## 一、测试环境准备

### 1.1 测试前置条件

| 序号 | 条件 | 说明 |
|------|------|------|
| 1 | 华为云账号 | 已注册华为云账号，且拥有管理员权限（IAM管理权限） |
| 2 | 企业IdP系统 | 已部署支持SAML 2.0协议的企业身份提供商（如ADFS、Keycloak、Shibboleth等） |
| 3 | 网络连通性 | 企业IdP服务器与华为云之间的网络互通，浏览器可访问双方系统 |
| 4 | 时间同步 | 企业IdP服务器时间与华为云时间一致（均使用GMT时间），时区偏差将导致认证失败 |
| 5 | 测试用户 | 企业IdP中已创建至少2个测试用户（不同权限级别），如admin_user、readonly_user |
| 6 | 浏览器 | Chrome浏览器（建议安装"SAML Message Decoder"插件，用于调试SAML消息） |

### 1.2 华为云IAM预配置

| 序号 | 配置项 | 操作说明 |
|------|--------|----------|
| 1 | 创建IAM用户组 | 在IAM控制台创建至少2个用户组，如`admin_group`（管理员权限）和`readonly_group`（只读权限） |
| 2 | 授权用户组 | 为用户组分别授予对应策略：`admin_group`授予`AdministratorAccess`策略；`readonly_group`授予`ReadOnlyAccess`策略 |
| 3 | （IAM用户SSO专用）创建IAM用户 | 创建IAM子用户，并配置外部身份ID（External Identity ID），与IdP中的用户属性对应 |
| 4 | 获取华为云SP元数据 | 在IAM控制台下载华为云的SP Metadata XML文件，用于后续在企业IdP中配置 |

### TC-01：创建身份提供商（虚拟用户SSO）

| 项目 | 内容 |
|------|------|
| **用例编号** | TC-01 |
| **用例名称** | 创建虚拟用户SSO类型的身份提供商 |
| **优先级** | P0（阻塞） |
| **预置条件** | 1. 已登录华为云控制台，拥有IAM管理权限<br>2. 尚未创建任何身份提供商，或已存在的身份提供商类型为虚拟用户SSO |
| **操作步骤** | 1. 进入华为云控制台，选择"统一身份认证服务IAM"<br>2. 在左侧导航栏点击"身份提供商"<br>3. 点击右上角"创建身份提供商"<br>4. 填写参数：<br>&nbsp;&nbsp;- 名称：输入唯一标识，如`enterprise_idp_v1`<br>&nbsp;&nbsp;- 协议：选择 **SAML**<br>&nbsp;&nbsp;- 类型：选择 **虚拟用户SSO**<br>&nbsp;&nbsp;- 状态：选择 **启用**<br>&nbsp;&nbsp;- 描述：（可选）输入如"企业IdP虚拟用户SSO测试"<br>5. 点击"确定" |
| **预期结果** | 1. 身份提供商创建成功，页面返回身份提供商列表<br>2. 列表中显示新创建的身份提供商，协议为SAML，类型为"虚拟用户SSO"，状态为"启用"<br>3. 点击"查看"可进入身份提供商详情页，显示登录链接和元数据配置区域 |

### TC-04：上传企业IdP元数据文件（文件上传方式）

| 项目 | 内容 |
|------|------|
| **用例编号** | TC-04 |
| **用例名称** | 通过上传元数据文件方式配置企业IdP的SAML元数据 |
| **优先级** | P0（阻塞） |
| **预置条件** | 1. 已创建SAML类型的身份提供商（TC-01或TC-02已完成）<br>2. 已从企业IdP导出SAML Metadata XML文件（文件大小<500KB）<br>3. Metadata文件包含有效的Entity ID、签名证书（>=2048位）、SSO服务地址 |

| **预期结果** | 1. 文件上传成功，系统自动解析出元数据参数<br>2. 正确显示：Entity ID（企业IdP标识）、签名证书信息、SingleSignOnService地址<br>3. 保存成功，身份提供商详情页显示已配置的元数据信息 |

| **用例名称** | 下载华为云SP元数据文件并上传至企业IdP，完成双向互信配置 |
