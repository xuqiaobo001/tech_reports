## 三、各服务计费项明细

### 3.1 APIG（API 网关）

| 计费项 | 说明 |
|--------|------|
| 实例费 | 按实例运行时长计费（按秒） |

**计费规则**：
- 计费起点：部署在 API 网关上的**实例启动运行时间**
- 计费终点：实例**停止/释放时间**
- 结算：每小时整点结算一次

**参考**：[APIG 按需计费](https://support.huaweicloud.com/price-apig/apig_08_0003.html)

---

### 3.2 EIP（弹性公网 IP）

EIP 按需计费有三种模式，费用组成不同：

| 按需模式 | 费用组成 |
|---------|---------|
| **按带宽计费** | EIP 保有费 + 带宽费（阶梯计费） |
| **按流量计费** | EIP 保有费 + 流量费（仅出云方向） |
| **加入共享带宽** | EIP 保有费 + 共享带宽费 |

**计费规则**：
- 计费起点：EIP **创建成功**时间
- 计费终点：EIP **释放**时间
- 结算：每小时整点结算一次
- **EIP 保有费**：未绑定云资源时收取（约 0.02 元/小时）
- **带宽费**：阶梯计费，0~5Mbit/s 统一单价，>5Mbit/s 另计
- **流量费**：仅出云方向（从华为云 → 互联网），入云不收费
- 绑定云资源时不收保有费，解绑后恢复收取

**计费示例（按带宽）**：

| 时间段 | 状态 | 费用 |
|--------|------|------|
| 08:45:00 ~ 09:45:00（未绑定） | 收保有费 + 带宽费 | 0.02 + 0.565 = 0.585 元 |
| 09:45:00 ~ 次日 06:45:00（已绑定） | 仅收带宽费 | 按时长 × 带宽单价 |
| 06:45:00 ~ 08:55:00（解绑后） | 收保有费 + 带宽费 | 至释放 |

**参考**：[EIP 按需计费](https://support.huaweicloud.com/price-eip/eip_billing_0007.html)

---

### 3.3 ELB（弹性负载均衡）

不同实例类型的计费项：

| 实例类型 | 规格 | LCU 费用 | 实例费用 |
|---------|------|---------|---------|
| 独享型 | 弹性规格 | 收取 | 收取 |
| 独享型 | 固定规格 | 收取 | 不收取 |
| 共享型 | 固定规格 | 不收取 | 收取 |

**计费规则**：
- 计费起点：ELB 实例**创建成功**时间（详情页"基本信息"中的创建时间）
- 计费终点：实例**删除**时间
- 结算：每小时整点结算一次
- 独享型支持多可用区部署，LCU 数量 = 单 AZ 的 LCU 数 × AZ 数

**计费示例**：

| 计费项 | 时间段 | 费用 |
|--------|--------|------|
| 网络型规格费（10 LCU） | 9:30 ~ 次日 12:00（共 1590 分钟） | 1590/60 × 0.417 = 11.0505 元 |
| 应用型规格费（10 LCU） | 9:30 ~ 次日 10:00（共 1470 分钟） | 1470/60 × 0.417 = 10.2165 元 |
| 应用型规格费（20 LCU，升配后） | 10:00 ~ 12:00（120 分钟） | 120/60 × 0.834 = 1.668 元 |
| **合计** | — | **22.935 元** |

**参考**：[ELB 按需计费](https://support.huaweicloud.com/price-elb/elb_billing_0302.html)

| 计费项 | 说明 |
|--------|------|

## 四、统一结算机制示意

```
所有 5 个服务统一结算机制

资源创建 ──→ 按秒累计使用时长 ──→ 每小时整点结算 ──→ 延迟约 1 小时出账扣费
                                                  │
                                           例如：8:00~9:00 的费用
                                           通常在 10:00 前完成扣费
```

## 五、通用注意事项

### 5.1 配置变更

同一小时内变更配置，会产生**多条计费记录**，每条按不同配置的生效时间分别计算。

### 5.2 费用精度

实际扣费精确到**分（0.01 元）**，超出部分直接抹去。

### 5.3 欠费流程

```
正常使用 → 欠费（余额为负）→ 宽限期（资源仍可用）→ 保留期（资源冻结）→ 资源释放（不可恢复）
```

- 某个按需业务欠费**不会**立即影响其他按需业务
- 宽限期和保留期时长根据客户等级不同

### 5.4 EIP 闲置费

EIP 未绑定任何云资源时，会收取**EIP 保有费**（闲置费），建议不使用时及时释放。
